# قرار الإطلاق

هذه نسخة تطوير قابلة للتجربة، وليست إعلانًا بأن كل مواصفات المنتج اكتملت 100%.

| البوابة | الحالة |
|---|---|
| مستودع مستقل وكود Django وواجهات RTL | منفذ محليًا |
| قاعدة بيانات محلية ومهاجرات وعضوية المنشأة | منفذ محليًا |
| دورة تشغيل واختبارات مالية وعزل ومستندات | راجع QA.md لنتائج التشغيل |
| اختبار التزامن PostgreSQL على الاستضافة المستهدفة | مطلوب قبل الاعتماد |
| استضافة فعلية ونطاق وHTTPS وبريد | يحتاج موارد الاستضافة؛ لم ينشر |
| فوترة إلكترونية ZATCA واعتماد متطلبات المنشأة | غير منفذ؛ كل الفواتير عليها علامة تجريبية |
| ربط منصات الحجز | مؤجل؛ المصادر إدخال يدوي |
| اشتراكات إلكترونية وبوابة تحصيل وإلغاء | غير منفذ؛ التجربة والتجديد يدويان |
| إدارة أنواع وأسعار وسياسات معقدة ومستقلة | النسخة الحالية حقول مبسطة داخل الوحدة والإعدادات |
| وثائق نزلاء ومرفقات وتوقيع سندات | ليست في هذه النسخة |
| قفل يوم التشغيل / Night Audit محاسبي | غير منفذ؛ تقارير بتاريخ الخدمة فقط |
| تقارير بحسب المصدر وأداء الوحدة مع نوعها | منفذة ضمن تقرير الفترة؛ ليست محاسبة ربحية بعد المصروفات |
| سياسة خصوصية وشروط دعم واحتفاظ واستضافة بيانات | يجب تخصيصها لجهة التشغيل قبل العملاء الحقيقيين |
| اختبار حمل طويل وتشغيل منشأة تجريبي 5 أيام | لم ينفذ |

يمكن مشاركة تجربة خاصة ببيانات وهمية بعد مراجعة نتائج الاختبار والنشر التجريبي. لا تسوق النسخة كنظام معتمد للفوترة أو Channel Manager أو محاسبة شاملة.
