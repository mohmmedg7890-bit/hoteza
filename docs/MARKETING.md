# خطة إطلاق Hoteza — مسودة تنفيذ بعد جاهزية التجربة

## العرض الأول

الشريحة: منشآت شقق مخدومة صغيرة تحتاج توحيد الحجز والوحدات والتحصيل. الرسالة: «تابع حجزك ووحداتك وحساب النزيل من شاشة تشغيل عربية واحدة». لا نستخدم ادعاءات زيادة الربح أو منع الأخطاء بنسبة 100% أو اعتماد ضريبي أو ربط منصات غير موجود.

## الأسبوع 1: تحضير عرض قابل للإثبات

- فيديو من 90–120 ثانية ببيانات وهمية: حجز ثم تسكين وتحصيل وتقرير.
- صفحة تعريفية بصور فعلية وطلب عرض تجريبي، مع توضيح الوظائف المتاحة وحدود التجربة.
- دليل بدء من صفحة واحدة وحساب عرض منفصل لا يسمح بمشاهدة بيانات عميل آخر.
- تحديد سعر تجريبي بعد حساب الاستضافة والنسخ والدعم والتجهيز؛ السعر ليس محسومًا في هذه الخطة.

معيار الإنجاز: تنفيذ العرض كاملًا دون تدخل في قاعدة البيانات أو وعود عن ميزات مؤجلة.

## الأسبوع 2: اكتشاف المشكلة لدى 5 منشآت

اجمع بموافقة المنشأة: طريقة العمل الحالية، وقت إنشاء الحجز، أكثر حالات التعارض، وطريقة مراجعة المقبوض والمتبقي. اعرض تجربة واحدة مناسبة للمشكلة. لا ترسل رسائل أو تتصل بأحد تلقائيًا من هذه الخطة.

معيار الإنجاز: خمس مقابلات موثقة، ومشكلتان متكررتان، ومنشأتان تبديان اهتمامًا واضحًا بتجربة محددة.

## الأسبوع 3: تجربة محدودة لمنشأة واحدة

نطاق مكتوب، مسؤول مستخدم واحد، بيانات وهمية أولًا، دعم يومي محدد، وقائمة بلاغات. قياس إتمام العمليات والفروقات ومدة التدريب. أي بيانات حقيقية تتطلب استيفاء بوابات التشغيل والخصوصية والفوترة في RELEASE_GATES.

معيار الإنجاز: إكمال دورة التشغيل خمسة أيام دون أخطاء حرجة أو فروقات مالية غير مفسرة، وتوثيق ملاحظات المستخدم دون اختراع تقييم أو موافقة.

## الأسبوع 4: قرار الاشتراك والتوسع

أصلح أعلى ثلاث مشكلات. قدم عرضًا مكتوبًا بنطاق الخدمة والدعم والنسخ والإلغاء والسعر. اطلب تقييمًا أو إحالة بعد نجاح التسليم وموافقة العميل على نشرها. ابدأ التوسع تدريجيًا؛ لا تُطلق إعلانات مدفوعة قبل معرفة نسبة تحويل العروض إلى اشتراك وتكلفة الدعم.

## لوحة القياس

| المؤشر | التعريف |
|---|---|
| العملاء المحتملون | منشآت وافقت على مناقشة الاحتياج |
| العروض | عدد العروض المكتملة |
| التجارب النشطة | منشآت بدأت دورة التشغيل |
| التحويل | المشتركون المدفوعون ÷ التجارب المنتهية |
| جودة التشغيل | العمليات الناجحة، الأخطاء الحرجة، وفروق الحساب |
| تكلفة الدعم | ساعات الدعم لكل منشأة أسبوعيًا |
| الاحتفاظ | المنشآت التي جددت من المستحق تجديدها |

هذه خطة عمل مقترحة، وليست نتائج سوق أو عقودًا أو حملات نُفذت.
