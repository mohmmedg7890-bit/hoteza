## غير مختبر أو غير منفذ

لم ينفذ اختبار حمل طويل أو تشغيل منشأة فعلية أو نشر DNS/TLS أو تكامل ZATCA أو إرسال SMTP فعلي. ملفات Docker وCompose مُعدة لكنها لم تُشغل محليًا لغياب Docker. فحص Python للإنتاج لا يثبت صحة DNS أو TLS أو إعداد استضافة بعينها.

ليست هذه النتائج ادعاء خلو كامل من الأخطاء أو جاهزية بيع شاملة. راجع RELEASE_GATES.md.
