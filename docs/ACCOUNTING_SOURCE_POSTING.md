# ترحيل مصادر التشغيل بعد المعاينة — المرحلة الثانية

## الوظيفة
إعداد قيود من مصادر فعلية، بعرض المعاينة للمالك ثم اعتمادها في معاملة ذرية. لا تشغيل تلقائي ولا تطبيق على قاعدة الإنتاج ضمن هذا التغيير.

المصادر المدعومة:
- سند قبض أو استرداد: حركة صندوق/بنك/مستحقات بطاقات مقابل مقدمات العميل، بتاريخ السند. لا إيراد ثانٍ عند التحصيل.
- سند صرف: مصروف تشغيلي مقابل وسيلة الدفع، دون تخفيض رصيد النزيل أو افتراض ضريبة مدخلات قابلة للاسترداد.
- إقامة مسجلة الخروج: رسوم مفوترة حسب تاريخ الخدمة، فصل الإقامة عن الخدمات/التصحيحات العامة والضريبة المنقولة من المصدر، ثم تخصيص المقدمات بحسب رصيد الإيراد والمقبوض المتراكم لكل يوم. الليالي المستقبلية المعكوسة بالكامل لا تولد إيرادًا.

مستحقات البطاقات لا تعامل كتحويل بنكي حتى تنفيذ تسوية بوابة/بنك مستقلة مستقبلًا. حساب 4010 يجمع الخدمات والتصحيحات العامة؛ تصنيف الغرامات والتصحيحات التفصيلي ليس مكتملًا.

## مسار الاستخدام في فرع المراجعة
1. يهيئ المالك الدليل من شاشة دفتر الأستاذ.
2. يختار نوع المصدر ثم السند أو الإقامة المغلقة.
3. يضغط «معاينة القيود» ويراجع التاريخ والمصدر والحساب والمبالغ والحالة.
4. يضغط «اعتماد ترحيل المصدر» ثم يؤكد. يعاد إعداد الخطة داخل قفل العقار وتفحص البصمة قبل الكتابة.
5. تكرار الطلب بنفس مفتاح العملية يعيد نتيجته. المعاينة الجديدة تتعرف على المصادر المرحلة سابقًا ولا تكررها.
6. تغير مصدر سبق ترحيله أو عكس قيده يمنع الاعتماد ويطلب مطابقة يدوية، دون تعديل أو إعادة ترحيل صامت.

المسار التقني: GET /api/ledger/preview/ للقراءة، وPOST /api/action/journal_import/ للاعتماد مع kind وsource_id وdigest ومفتاح العملية. لا يقبل الخادم من المتصفح مبالغ القيود أو حساباتها لهذه العملية؛ يعيد بناءها من المصدر. كل كتابة تخضع لعضوية المالك والتدقيق.

## نطاق المحاسبة
هذه سياسة داخلية تجريبية بتاريخ الخدمة؛ ليست محرك تحديد الاستحقاق الضريبي، ولا إثبات ZATCA. لا تنشر قبل مراجعة السياسة والافتتاحيات وتاريخ القطع والنسخ والاستعادة. لا ترحّل سجلًا سبق تضمينه في افتتاحيات يدوية حتى لا يتكرر رصيده.

لا يشمل هذا الإصدار:
- الاستحقاق الليلي التلقائي للحجوزات المفتوحة أو الترحيل الخلفي المجدول.
- إعادة بناء تاريخ كامل من بيانات معدلة سابقًا أو استيراد افتتاحيات آلي.
- الإقفال وقفل الفترة، والمطابقة البنكية والصندوقية، والموردين والذمم الدائنة أو التأمينات التفصيلية.
- التصحيحات التي أضيفت بتاريخ لاحق للخروج؛ تتوقف للمراجعة اليدوية ضمن السياسة الحالية.
- قائمة دخل شاملة أو ميزانية، أو ضمان تطابق جميع أرصدة التشغيل مع الدفتر؛ المعروض يشمل المصادر المعتمدة فقط.

الضمانات الحالية عبر حدود خدمات التطبيق ومعاملاتها؛ SQL المباشر خارج هذه الحدود كما هو موثق في ACCOUNTING_FOUNDATION.md.

## اختبارات مضافة
قبض قبل الإقامة يبقى مقدمات، تخصيصه دون تكرار الإيراد، ذمم عند السداد الجزئي، تحصيل متأخر، صرف لا يغير حساب النزيل، رد زيادة، رفض البصمة القديمة، رفض مصدر مرحل تغير، الصلاحيات والعزل، التراجع الذري عند حساب مفقود، اعتماد API ومفتاح التكرار والتدقيق، واستبعاد الليالي المستقبلية الملغاة. اختبار واجهة يعاين إقامة مغلقة ويعتمدها ثم يؤكد أن المعاينة التالية لا تولد قيودًا جديدة.
