# الخطة الأسبوعية المحدثة

الإيقاع: ساعتان يوميًا، ستة أيام = 12 ساعة أسبوعيًا. كل يوم 20 دقيقة تعلم، 80 تنفيذ، 20 تحقق وتوثيق. الأسابيع ترتيب عمل وليست وعد موعد تسليم؛ تُمدد المرحلة حتى اجتياز معيارها. لم توجد خطة تطوير أسبوعية أصلية كاملة في المستودع؛ جرى حفظ المكتمل المثبت في الشيفرة وسياق المشروع، دون اختلاق نسخة قديمة. docs/MARKETING.md خطة تسويق مستقلة.
